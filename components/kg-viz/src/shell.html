Open a graph

This viewer starts empty and will display any compatible graph file — one with a top-level views array.

The default is payments.json, in this same folder — embedded in this page at build time, so Load default needs no file dialog.

Or drop a .json file anywhere on this window. Regenerate payments.json from the knowledge graph with python3 generate.py then python3 build.py; you can reopen or switch files at any time from the left panel.
